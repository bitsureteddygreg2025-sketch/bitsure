# OBJECTIF GLOBAL

Le projet est composé de 3 parties :
1. Bot de trading (Python)
2. Base de données PostgreSQL (Railway)
3. Dashboard web (Teddy-web)

Le système est censé fonctionner en TEMPS RÉEL :
- le bot génère des signaux
- les signaux sont stockés dans PostgreSQL
- le dashboard affiche les données à jour immédiatement

---

# PROBLÈME ACTUEL

Le dashboard :
- affiche des données obsolètes
- affiche parfois des prix incohérents ou inexistants
- ne semble pas synchronisé avec le bot
- ne reflète pas les dernières données de la base PostgreSQL

---

# OBJECTIF DE TA MISSION

Tu dois analyser TOUT le projet et corriger les problèmes suivants :

## 1. Synchronisation temps réel
- Vérifier si le dashboard recharge les données dynamiquement
- Vérifier si des caches frontend existent (React/Vue/local cache/API cache)
- Vérifier si les endpoints API renvoient des données fraîches
- Corriger tout système de cache bloquant les mises à jour

---

## 2. Cohérence base de données
- Vérifier que toutes les requêtes utilisent PostgreSQL (pas SQLite)
- Vérifier que toutes les tables sont correctement utilisées :
  - users
  - usage
  - settings
  - watchlist
  - alerts
  - signals
  - paper_positions
  - paper_capitals

- Vérifier qu’il n’y a pas de données simulées ou mock data dans le frontend

---

## 3. Problème des prix incohérents
Le site affiche des prix qui ne correspondent pas à la réalité.

Tu dois :
- Identifier la source des prix (API, bot, cache, fallback)
- Vérifier si les prix sont :
  - stockés en DB
  - calculés côté backend
  - ou récupérés d'une API externe

- Corriger toute logique qui génère des prix faux ou figés

---

## 4. Analyse du bot (important)
- Vérifier comment le bot écrit les signaux en base
- Vérifier si les données sont mises à jour ou seulement insérées une fois
- Vérifier si les timestamps sont corrects (created_at / updated_at)
- Vérifier si le bot et le dashboard utilisent exactement la même DATABASE_URL

---

## 5. API backend
- Vérifier tous les endpoints utilisés par le dashboard
- Vérifier :
  - filtres incorrects
  - LIMIT trop bas
  - données partiellement renvoyées
  - erreurs silencieuses

---

## 6. Correction attendue

À la fin :

- le dashboard doit afficher des données en temps réel
- les signaux doivent être synchronisés avec le bot
- les prix doivent être cohérents et issus d’une seule source fiable
- aucune donnée mock ou obsolète ne doit exister
