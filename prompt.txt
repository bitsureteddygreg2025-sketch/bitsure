Tu es une IA senior chargée de développer et d’améliorer un bot de trading déjà existant.

Avant toute modification, tu dois te ressourcer dans le code déjà présent, lire le projet existant, comprendre son architecture, ses conventions, ses menus, sa logique métier, sa base de données, et ses flux actuels. Tu ne dois pas repartir de zéro. Tu dois t’appuyer sur le code en place, en respectant sa structure autant que possible.

Ta mission est de mettre en œuvre uniquement les besoins suivants, sans inventer de fonctionnalités non demandées :

1. Organisation des commandes et des menus

- Chaque commande doit être placée soit dans un sous-menu, soit dans un menu principal.
- Le choix dépend de la nature de la commande :
  - si la commande appartient à une catégorie, elle doit aller dans le menu de cette catégorie ;
  - si la commande représente une catégorie à elle seule, elle doit devenir un menu principal.
- La navigation doit rester claire, logique et cohérente.

2. Sélection du mode de trading

- Ajouter une option permettant de choisir temporairement entre :
  - spot
  - futures
- Ce choix doit être accessible dans un menu spécifique dédié à cette sélection.
- Le bot doit pouvoir utiliser ce mode sélectionné pendant la session ou pendant la période prévue par la logique du projet.

3. Nouveau style de trading

- Ajouter la possibilité de trader en scalping sur timeframe 5 minutes.
- Ajouter aussi un autre timeframe en plus de celui-ci.
- Le système doit être capable de distinguer ce nouveau style de trading des autres styles déjà existants.

4. Analyse périodique du marché

- Le bot doit analyser automatiquement le marché toutes les 5 minutes ou toutes les 10 minutes selon la configuration choisie.
- À chaque analyse, il doit parcourir tous les symboles tradables sur Binance.
- Pour chaque symbole, il doit déterminer s’il peut ouvrir une position ou non.
- À la fin de l’analyse, il doit produire un rapport clair du résultat.

5. Gestion des signaux Wait

- Les signaux “Wait” ne doivent pas être enregistrés.
- Ils ne doivent être sauvegardés ni dans la base de données, ni dans l’historique.
- Ils ne doivent pas être traités comme des résultats persistants.
- Seuls les signaux réellement utiles doivent être conservés.

Contraintes d’implémentation :

- Ne casse pas l’existant.
- Réutilise le code déjà présent quand c’est possible.
- Garde une architecture propre, lisible et extensible.
- Adapte les modifications au projet actuel au lieu d’écrire une solution générique détachée du code existant.
- Vérifie les impacts sur les menus, la logique de trading, la persistance des données, et le système de rapport.
- Si quelque chose dépend d’une partie du code déjà présente, base-toi d’abord sur cette base avant d’écrire du nouveau code.

Objectif final :
un bot cohérent, structuré, capable de gérer les menus, le choix spot/futures, le scalping 5 minutes, l’analyse périodique de tous les symboles Binance, et l’exclusion totale des signaux “Wait” du stockage.
